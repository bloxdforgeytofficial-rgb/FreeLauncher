### 🚀 FreeLauncher 3.0 — Modded Gaming Edition

FreeLauncher 3.0 is a standalone, ultra-premium offline launcher client built for Minecraft Java Edition. It offers a sleek dark-themed interface, full Discord integration, dynamic RAM management, and single-click access for mod loaders. 

### ✨ Features

* 🌌 **Sleek Midnight UI:** Clean geometric container card with responsive hover state configurations.
* 📦 **Direct Mojang Pipeline:** Downloads unmodded official assets directly from game servers safely.
* 🛠️ **Mod Loader Integration:** Built-in compiler hooks to seamlessly toggle between Vanilla, Fabric, and Forge.
* 🎨 **Discord Rich Presence:** Dynamic status system showing friends what username and game version you are playing.
* 📁 **Mods Folder Shortcut:** Single-click interface button to instantly drop optimization mod JARs right into place.

### 🎛️ Dynamic RAM Tuning Guidelines

FreeLauncher features a built-in memory allocation control slider to boost your FPS. Setting this correctly is crucial to keep your operating system stable. 

### 💡 For Systems with 8 GB Total RAM:

* **Recommended Slider Target:** **3 GB**
* **Why?** Allocating 3 GB gives Minecraft plenty of breathing room to load heavy chunks (especially legacy versions like 1.9 or 1.16), while leaving 5 GB free for Windows, Discord, and system stability to prevent freezes.

### ⚙️ General Scaling Rules:

* **4 GB System Total:** Set slider to **2 GB**
* **16 GB System Total:** Set slider to **4 GB - 6 GB**

### 🔧 How to Use Mods

1. Open **FreeLauncher 3.0**.
2. Click the **📁 OPEN MODS FOLDER** button to view your directory.
3. Download the exact matching version of your mod (e.g., Sodium .jar file for 1.20.1) from CurserForge or Modrinth.
4. Drag and drop the downloaded .jar file directly into that open folder window.
5. In the launcher UI, switch the **Modding Utility Engine** dropdown to **Fabric Loader** or **Forge Loader** and click **LAUNCH CLIENT**.
